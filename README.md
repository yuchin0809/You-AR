# You AR

カメラ越しの世界で、3Dの「あなた」と一緒に暮らすWebAR育成アプリ。ごはんをあげる・なでる・話しかける・一緒に自撮りする。実際の時間でおなかが減ったり眠くなったりします。ビルド不要の静的サイトです。

## ファイル構成
- `index.html` 画面 / `style.css` 見た目
- `app.js` 土台(カメラ・3Dモデル・ジェスチャ・自撮り・会話)。`window.YouAR` で機能を公開
- `pet.js` 育成(ステータス・ごはん・なでる・睡眠・成長・出迎え・通知・バックアップ)。`YouAR.hooks` に処理を差し込む
- `sw.js` オフライン起動と、閉じている間の通知 / `manifest.json`・`icons/` ホーム画面に追加するための情報

サーバーは使いません。すべて端末の中で動き、データも端末に保存されます。

## 使い方
1. HTTPSで公開する(カメラにはHTTPSかlocalhostが必須。GitHub Pagesが手軽)。ローカル確認は `python3 -m http.server 8000`。
2. スマホで開き、「自分の3Dモデル(.glb)を選ぶ」→「ARを始める」。
3. 1本指でなでる、タップでつつく、2本指で移動・拡大・回転、何もない所をダブルタップでそこへ歩いていく。「空間に固定」で、スマホを動かしても同じ場所に立って見えます(ジャイロ使用)。
4. 下の入力欄に打つか、🎤で話しかける。📷で合成画像を保存。
- リポジトリ直下に `me.glb` を置くと、起動時に自動で読み込まれます。

## 3Dモデルの作り方
1. 自分の周りを撮った動画を Luma AI / Polycam に入れて3Dモデルを作る(`.glb`)。明るく均一な光・無地の背景・静止・全身を3段階の高さで一周・顔アップも別に一周・Aポーズ。
2. Mixamo(無料)にアップロードして骨格を自動で入れる。
3. Mixamoで好きな動き(Waving / Hip Hop Dancing / Happy / Sad / Nodding …)を選び、「Without Skin」で書き出す(`.fbx`は`.glb`に変換)。
4. サイトで本人の`.glb`を選び、⚙設定の「モーションを追加」で動きの`.glb`を複数追加する。

## 動きの選ばれ方
- ファイル名に dance / wave / happy / sad / nod / shake / surprise などが含まれると、その場面で使われます。
- 分類できないモーションは、どの場面でもランダムに使われます。
- 同じ場面に候補が複数あると毎回ランダムに選び、直前と同じものは避けます。
- 名前に idle が含まれるものは待機ループになります。
- モーション未登録のときは、モデル全体を跳ねる・傾くなどで反応させます。

## 話しかけ
- 音声認識はChrome / Safari(Chromeでは音声がGoogleのサーバーで処理されます)。
- 標準はキーワード判定(無料・即時)。⚙設定で「AIで理解」を入れると、ブラウザ内のAI(WebLLM、WebGPU必須、初回約1GB)が要約して返事を考えます。
- 返事は吹き出しと、端末の音声合成で出ます。

## 育成
- ステータス:🍙おなか / 😊きげん / ⚡げんき / 💗なかよし(経験値→レベル)。実時間で変化し、この端末のブラウザに保存されます。
- ごはん:🍙ボタン → 食べ物を選び、僕に向かってフリックで投げる(直接ドラッグでもOK)。大好物が1つ隠れています。甘いものばかりだと気持ち悪くなる、ブロッコリーは苦手、おなかいっぱいだと食べない。
- レベルが上がると食べ物が解放されます(ケーキLv2、おすしLv3、ラーメンLv4、チョコLv5、おにくLv7)。なかよしの称号も変わります。
- なでると喜び、つつきすぎると怒る。💤で寝かせる(元気だと寝ない)。寝ている間はげんきが回復し、話しかけても寝言。起こすと少し不機嫌。
- 開くたびに「おはよう」「おかえり!○時間ぶり」などと出迎え。おなかが減ると訴え、ほっとくと自分から話しかけてきます。
- 「おなかすいた?」「元気?」「名前は?」「好きな食べ物は?」「何日目?」「ただいま」「眠い?」には状態に合わせて答えます。

## 自撮り
- 🤳で内カメラに切り替わり、僕が隣に並びます。シャッターで3秒カウントダウン→僕がポーズ→撮影。
- 保存は共有シート(写真に保存)を使い、無理な端末ではダウンロードします。

## 無料で公開する(GitHub Pages)
1. GitHubのリポジトリで Settings → Pages を開く。
2. 「Build and deployment」の Source を「Deploy from a branch」にし、公開したいブランチ(例:main)と `/ (root)` を選んで Save。
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開されます(HTTPSなのでカメラも使えます)。

## アプリとして使う(PWA)
- スマホのブラウザで開き、メニューの「ホーム画面に追加」。アプリのように起動でき、一度開けば通信なしでも動きます。
- 選んだ3Dモデルとモーションは端末に保存され、次回から自動で読み込まれます。

## 通知
- ⚙設定の「おなかがすいたら通知」をオン。
- アプリを閉じている間の通知は、ホーム画面に追加したAndroidのChromeで動きます(Periodic Background Sync。頻度はブラウザが決め、数時間おき程度)。
- iPhoneなど、それ以外の端末では、アプリを開いている間(裏に回している間を含む)だけ通知します。閉じている間に確実に通知するにはプッシュ用のサーバーが必要なため、対応していません。

## 機種変更
- ⚙設定の「バックアップを保存」でファイルを書き出し、新しい端末で「バックアップから復元」。3Dモデルは含まれないので、新しい端末でもう一度選んでください。
