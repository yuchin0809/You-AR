# You AR

カメラ越しの映像に「自分」を重ねて登場させるWebARサイト。ビルド不要・依存ゼロの静的サイトです。

## 使い方
1. HTTPSで公開する(カメラ利用にはHTTPSかlocalhostが必須)。GitHub Pagesが手軽です。
2. スマホでアクセス →「自分の写真を選ぶ」→「ARを始める」。
3. ドラッグで移動、2本指で拡大・回転。「空間に固定」で、スマホを動かしても同じ場所に立って見えます(ジャイロ使用)。
4. 📷で合成画像を保存。

## ヒント
- 全身写真を、無地の壁の前で撮ると「背景を消す」で綺麗に切り抜けます。
- 透過PNGならそのまま使えます。リポジトリ直下に `me.png` を置くと自動で読み込まれます。
- ローカル確認: `python3 -m http.server 8000` → http://localhost:8000

## 話しかけると反応する
- 下の入力欄に打つか、🎤で話しかけます(音声認識はChrome / Safari。Chromeでは音声がGoogleのサーバーで処理されます)。
- 標準はキーワード判定(無料・即時)。⚙設定で「AIで理解」を入れると、ブラウザ内のAI(WebLLM / WebGPU必須)が要約して返事を考えます。
- 動作は、あいさつ・喜ぶ・悲しむ・バイバイ・うなずく・首を振る・驚く・踊る。⚙設定から動作ごとに本人の動画を登録できます。

## 3Dモデル(.glb)で登場させる
1. 自分の周りを撮った動画を Luma AI / Polycam に入れて3Dモデルを作る(`.glb`)。
2. Mixamo(無料)にアップロードして骨格を自動で入れる。
3. Mixamoで好きな動き(Waving / Hip Hop Dancing / Happy / Sad / Nodding …)を選び、「With Skin」でなく「Without Skin」で書き出す(`.glb`、または`.fbx`を`.glb`に変換)。
4. サイトで「3D(.glb)を選ぶ」→ 本人の`.glb`、⚙設定の「モーションを追加」→ 動きの`.glb`(複数可)。
- ファイル名に dance / wave / happy / sad / nod / shake / surprise が含まれると、その場面で使われます。分類できないものは、どの場面でもランダムに選ばれます。
- 同じ場面に複数のモーションがあると、毎回ランダムに選ばれ、直前と同じものは避けられます。
