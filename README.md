# You AR

カメラ越しの部屋で、3Dの「あなた」とルームメイトとして暮らすWebAR。話す・おやつを食べる・じゃんけんする・一緒に自撮りする。ビルド不要の静的サイトです。

## ファイル構成
- `index.html` 画面 / `style.css` 見た目
- `app.js` 土台(カメラ・3Dモデル・ジェスチャ・自撮り・会話)。`window.YouAR` で機能を公開
- `roommate.js` ルームメイト(生活リズム・うろうろ・記憶・会話・友達同士の行動・通知・バックアップ)。`YouAR.hooks` に処理を差し込む
- `sw.js` オフライン起動と、閉じている間の通知 / `manifest.json`・`icons/` ホーム画面に追加するための情報

サーバーは使いません。すべて端末の中で動き、データも端末に保存されます。

## 床の認識(AR)
- **Android の Chrome:** 「ARを始める(床を認識)」で、本物の床を認識します(WebXR)。スマホをゆっくり動かすと床に白い丸が出るので、暮らす場所の真ん中で「ここ」→ 広さ(ピンクの円)を決める。等身大の3Dが床に立って影を落とし、円の中を歩く方向を向いて歩き回り、話すときはこちらを向きます。2本指でつまむと大きさを変えられます。
- **iPhone:** Safari は床の認識に対応していないため、専用アプリ(ARKit)を準備中です。それまでは、画面上で範囲をなぞる通常モードで動きます。

## 使い方
1. HTTPSで公開する(カメラにはHTTPSかlocalhostが必須。GitHub Pagesが手軽)。ローカル確認は `python3 -m http.server 8000`。
2. スマホで開き、「ARを始める」。
3. 暮らす範囲をなぞって決め、大きさを合わせる。「空間に固定」で、スマホを動かしても同じ場所に立って見えます(ジャイロ使用)。
4. 下の入力欄に打つか、🎤で話しかける。📷で合成画像を保存。

## 3Dモデル(me.glb)
サイトには、本人の3Dモデル `me.glb` が最初から入っています(ファイルを選ぶ画面はありません)。

- **作り方:** 動画から切り出した写真を合成し(全身は体と足元を合成、顔はニキビだけを目立たなくする補正)、無料の TRELLIS(Hugging Face)で3D化。体と、顔のアップから作った高精細な頭を首でつなぎ、顔には写真を投影しています。
- **骨格と動き:** 骨格・各部の重み・動き(待機2種、歩く、手を振る2種、バイバイ、喜ぶ2種、悲しむ、うなずく2種、首を振る、驚く、踊る2種、食べる、照れる)はプログラムで作って組み込み済み。同じ場面に複数ある動きは、毎回ランダムに選ばれます。
- **表情:** 頭は「真顔」「笑顔(歯が見える)」の2つを持ち、場面で切り替えます。うれしい・あいさつ・踊る・食べるときは笑顔、それ以外は真顔。機嫌がとてもいいときは、普段から笑顔です。
- **注意:** 公開サイトなので、`me.glb` は誰でもダウンロードできます。

## 話しかけ
- 音声認識はChrome / Safari(Chromeでは音声がGoogleのサーバーで処理されます)。
- 標準はキーワード判定(無料・即時)。⚙設定で「AIで理解」を入れると、ブラウザ内のAI(WebLLM、WebGPU必須、初回約1GB)が要約して返事を考えます。
- 返事は吹き出しと、端末の音声合成で出ます。

## ルームメイトとして暮らす
世話をする相手ではなく、同じ部屋で暮らす友達です。ゲージやレベルは画面に出しません(内部の「機嫌」「眠さ」が、口調や動きに出るだけです)。

- **暮らす範囲:** 起動時に、床を映して指でなぞった範囲が「僕の居場所」になります。その中を自分でうろうろします(奥ほど小さく、手前ほど大きく表示)。大きさは2本指のつまみで調整、あとから⚙設定で決め直せます。ジャイロで部屋に固定されるので、スマホを動かしても同じ場所にいます。
- **生活リズム:** 本を読む・音楽を聴く・ゲームをする・お茶を飲む・窓の外を見る…を、時間帯に合わせて自分でします。夜は自分で寝ます(就寝時刻は日によって違います)。話しかけると寝言、3回続けると不機嫌に起きます。
- **友達同士の行動(🤝いっしょに):** 🍪おやつを一緒に食べる / 👋肩をたたく(僕をタップ)/ 💆肩をもんでもらう / ✋ハイタッチ(出た手をタップ)/ ✌️じゃんけん。僕の上で指を動かすと、肩をもんであげたことになります。何もない所をダブルタップすると、そこへ呼べます。
- **話す:** 入力欄か🎤。「疲れた」→肩をももうか?「暇」→じゃんけんする?「おなかすいた」→おやつ食べる?など、状況に合わせて答えます。誘うと一緒にやってくれます。
- **覚えている:** 名前・好きなもの・苦手なもの・予定(面接、旅行…)・疲れていたことを覚え、あとで「そういえば、面接どうだった?」と聞き返します。⚙設定の「おぼえていること」で確認・削除できます。
- **AIで会話(任意):** ⚙設定でオンにすると、ブラウザ内のAI(WebLLM。WebGPU必須、初回約1GB)が、記憶と時間帯を踏まえて自然に返事します。オフでも、上のルールベースで会話が成り立ちます。
- **出迎え:** 開くたびに「おかえり」「ひさしぶり!」などと迎えます。責めたり、ペナルティを与えたりはしません。

## 無料で公開する(GitHub Pages)
1. GitHubのリポジトリで Settings → Pages を開く。
2. 「Build and deployment」の Source を「Deploy from a branch」にし、公開したいブランチ(例:main)と `/ (root)` を選んで Save。
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開されます(HTTPSなのでカメラも使えます)。

## アプリとして使う(PWA)
- スマホのブラウザで開き、メニューの「ホーム画面に追加」。アプリのように起動でき、一度開けば通信なしでも動きます。

## 通知
- ⚙設定の「しばらく会わないと、ひとことメッセージ」をオン(24時間以上・72時間以上会わないときだけ。夜は送りません)。
- アプリを閉じている間の通知は、ホーム画面に追加したAndroidのChromeで動きます(Periodic Background Sync。頻度はブラウザが決め、数時間おき程度)。
- iPhoneなど、それ以外の端末では、アプリを開いている間(裏に回している間を含む)だけ通知します。閉じている間に確実に通知するにはプッシュ用のサーバーが必要なため、対応していません。

## 機種変更
- ⚙設定の「バックアップを保存」でファイルを書き出し、新しい端末で「バックアップから復元」。3Dモデルは含まれないので、新しい端末でもう一度選んでください。
