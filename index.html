3Dモデル

3Dモーション(.glb、複数選択可)

Mixamoなどで書き出した動き(骨格付き.glb)。ファイル名に dance / wave / happy / sad / nod / shake / surprise / eat / idle などが含まれると、その場面で使われます。分類できないものは、どの場面でもランダムに使われます。同じ場面の候補が複数あると、毎回ランダムに選びます。
